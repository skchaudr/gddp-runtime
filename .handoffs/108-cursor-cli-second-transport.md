`cursor-agent` subprocess per turn in a per-attempt worktree, its stream-json
translated to the canonical 7-event vocabulary, with coverage/cache/exit
evidence written by GDDP-owned shared code rather than a second copy. The only
cursor-specific logic is invocation shape, stream parsing, SIGTERM/SIGKILL, and
where the session id lives. `python3 -m pytest -q` is green: 828 passed (86 new,
742 baseline), no test skipped and no pre-existing failure.
