### Architecture summary

```
Heartbeat tick:
  Phase 0: Reconcile active sessions (NEW - runs every tick)
    → poll dispatched/running sessions
    → collect completed work into isolated worktree
    → apply patch, commit, trigger evaluation
  Phase A: Plan new events (existing)
  Phase B: Dispatch (existing, now stores session_ref for CLI adapters)
  Phase C: Record outcomes (existing, now inserts executor_session rows)
```

Adapter interface (executor-neutral):
```
dispatch(job) → SessionRef
status(ref) → SessionStatus(state, error)
collect(ref, dest) → PatchResult(patch_text, patch_path)
cancel(ref) → bool
```
