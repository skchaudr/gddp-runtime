## 2026-04-03 - Database Connection Consolidation in Return Router
**Learning:** In `scripts/runtime/return_router.py`, `_load_job`, `_mark_job_awaiting_review`, and `handle_merged_pr` were all independently opening and closing SQLite connections (`_connect()`). This created unnecessary connection overhead, particularly when processing merged PRs which call multiple database functions sequentially.
**Action:** Passing a shared SQLite connection down from `handle_merged_pr` to `_load_job` and `_mark_job_awaiting_review` eliminates redundant connection cycles. It also ensures operations are executed within a single transaction where appropriate, improving both efficiency and consistency. The optional `con` parameter pattern maintains backward compatibility with isolated function calls.
