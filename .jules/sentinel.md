## 2024-05-17 - [CRITICAL] Fail closed on missing webhook signature configuration
**Vulnerability:** The webhook intake server (`scripts/intake_server.py`) bypassed signature verification completely if the `GITHUB_WEBHOOK_SECRET` environment variable was not set, returning `True` (allow). This fails open, allowing anyone to bypass authentication and send malicious webhooks if configuration is missing.
**Learning:** Security controls must fail closed. When relying on environment variables or configuration for security mechanisms like webhook validation, the absence of configuration must result in denying access rather than allowing it. Missing configuration is a system state failure that should not degrade security boundaries.
**Prevention:** Always default to rejecting requests (fail closed) when authentication or authorization configuration is missing. Validate the presence of required security configuration at startup or request time, and deny access if it is not present.
