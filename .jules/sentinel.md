## 2026-04-03 - [Missing Authentication on Webhook Endpoint]
**Vulnerability:** The webhook payload signature validation function `verify_signature` in `scripts/intake_server.py` failed open (returning `True`) when the `GITHUB_WEBHOOK_SECRET` environment variable was empty or not set. Additionally, the `/webhook` endpoint code skipped signature verification entirely if `WEBHOOK_SECRET` evaluated to False.
**Learning:** This "fail-open" pattern is a critical risk for security gateways and webhooks. Defaulting to true when a configuration is missing allows trivial authentication bypass if deployment environments accidentally omit the secret or when exposing servers locally. Test suites also mirrored this insecure behavior by actively asserting that missing secrets result in successful verification.
**Prevention:** Always default to "fail closed" (deny by default) in security boundary components. Ensure that critical security configurations are mandatory for the application to function correctly. Ensure test suites validate secure failure modes for missing configurations.
