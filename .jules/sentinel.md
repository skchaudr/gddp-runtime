## 2024-06-15 - Prevent Stack Trace Exposure on Unhandled Webhook Payload Exceptions
**Vulnerability:** The `/webhook` endpoint in `intake_server.py` failed to gracefully handle `json.JSONDecodeError` from malformed JSON payloads and `sqlite3.Error` from invalid database insertions. These unhandled exceptions could lead to 500 Internal Server Errors that might inadvertently expose stack traces or internal application structures depending on the web server/Flask configuration.
**Learning:** External webhook endpoints receive completely untrusted inputs and must explicitly catch all expected edge cases (like JSON decoding errors or DB validation/insertion failures) to ensure an intentional, generic response structure.
**Prevention:** Always wrap parsing of untrusted JSON payloads in `try...except json.JSONDecodeError` and database operations in `try...except sqlite3.Error` within API endpoints. Return generic errors like `400 Bad Request` or `500 Internal Server Error` without leaking internal error specifics.
